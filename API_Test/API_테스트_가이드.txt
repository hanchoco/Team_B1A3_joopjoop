1. .env.example → .env 로 변경
   - UPSTAGE_API_KEY = (각자 본인 Upstage 키)
   - 온통청년 API 키도 같이 넣기 (하드코딩 금지, 이것도 .env로)

2. pip install -r requirements.txt --break-system-packages

3. test_connection.py 실행 → "연결 성공!" 확인

4. 개별 모듈 3개 순서대로 실행 (에러 없이 실행되는지만 확인)
   - python rule_extractor.py
   - python policy_qa.py
   - python application_checklist.py

5. 온통청년API_Test.py 실행
   → raw_policy_sample.json에 데이터 잘 담겼는지 확인 (한 줄 정상)

6. main.py 로컬실행 가이드대로 서버 실행
   → http://127.0.0.1:8001/health 로 서버 켜짐 확인
   → http://127.0.0.1:8001/docs 에서 각 엔드포인트 직접 눌러서 테스트
   → INFO:     127.0.0.1:54409 - "GET /favicon.ico HTTP/1.1" 404 Not Found 괜찮음, 서버에 아무것도 없는거 정상. 
   ctrl + c로 나오기
