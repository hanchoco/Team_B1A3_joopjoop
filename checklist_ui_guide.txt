====================================================================
가입 준비하기 화면 - AI 응답(JSON) -> 실제 화면 매핑 가이드
====================================================================

이 문서는 /checklist-explain 이 반환하는 JSON이 실제로 화면에서
어떤 모양으로 보여야 하는지 정리한 것입니다.
--------------------------------------------------------------------
1. AI가 주는 JSON 구조 (요약)
--------------------------------------------------------------------
{
  "condition_checklist": [
    { "attribute_key", "title", "status", "explanation",
      "possible_exception", "additional_note" }, ...
  ],
  "document_checklist": [
    { "title", "is_required", "tip" }, ...
  ],
  "summary": "전체 상황 요약 문장"
}

Backend/Policy Engine이 주는 것: condition_checklist의 status
  (충족 / 불충족 / 확인필요) <- 이 값은 AI가 아니라 Policy Engine이 계산합니다.
AI가 주는 것: explanation, possible_exception, additional_note,
  document_checklist의 tip, summary


--------------------------------------------------------------------
2. 조건 체크리스트 - 상태별 화면 (참고만 하세요)
--------------------------------------------------------------------

[status = "충족"]
  아이콘: ✓ (초록색)
  기본 표시: title + explanation 한 줄
  additional_note가 있으면: 아이콘 아래 작은 글씨로 추가 노출
    (예: "충족했지만 참고하세요 -> ...")

  (화면 예시)
  ✓ 나이                                   [충족]
     25세로 19~34세 조건을 충족합니다.


[status = "불충족"]
  아이콘: ✗ (빨간색)
  possible_exception이 null이 아니면:
    -> 아이콘을 ✗(빨강) 대신 △(주황)로 격상 표시하는 걸 권장
       ("완전히 끝난 게 아니라 예외 확인이 남았다"는 느낌을 주기 위함)
    -> explanation 아래에 "예외조항 확인해보기" 형태의 강조 박스로 possible_exception 노출
  possible_exception이 null이면:
    -> ✗(빨강) 그대로, explanation만 표시 (예외 없음을 솔직하게 안내)

  화면 예시 (예외 있음)
  △ 소득                                   [불충족 - 확인 필요]
     중위소득 60% 이하 조건을 충족하지 못합니다.

     ┌─ 예외조항 확인해보세요 ─────────────────┐
     │ 30세 미만 미혼 청년이 부모와 별도로       │
     │ 생계를 유지하는 경우 예외가 적용될 수      │
     │ 있습니다.                               │
     └───────────────────────────────────────┘

  화면 예시 (예외 없음))
  ✗ 나이                                   [불충족]
     41세로 19~34세 조건에 해당하지 않습니다.
     (관련 예외조항 없음)


[status = "확인필요"]
  아이콘: △ (주황색)
  explanation 그대로 노출, possible_exception도 있으면 같이 노출


--------------------------------------------------------------------
3. 서류 체크리스트 (document_checklist)
--------------------------------------------------------------------
  각 항목: 체크박스 + 제목 + [필수/선택] 배지 + tip(작은 회색 글씨)

  (화면 예시)
  [ ] 월세지원 신청서                        [필수]
      온라인 제출 시 PDF 형식으로 작성 권장

  [ ] 소득·재산 신고서                       [필수]
      세무서 발급 최신 자료 제출

  [ ] 신분증                                [선택]
      온라인 신청 시 생략 가능하나, 현장 제출 시 사본 권장


--------------------------------------------------------------------
4. 전체 요약 (summary)
--------------------------------------------------------------------
  화면 최상단 또는 최하단에 안내 배너 형태로 노출 추천.
  예: "총 2개 조건 중 1개 충족, 1개는 확인이 필요해요. 서류 2종을
      준비하시고, 예외조항 해당 여부를 먼저 확인해보세요."


--------------------------------------------------------------------
5. 전체 화면 흐름 예시 (실제 실행 결과 기반)
--------------------------------------------------------------------

  [배너] 총 2개 조건 중 1개(나이) 충족, 1개(소득)는 확인이 필요해요.

  자격 조건
  ─────────────────────────────────────────
  ✓ 나이                                   [충족]
     25세로 19~34세 범위에 해당됩니다.

  △ 소득                                   [불충족 - 확인 필요]
     중위소득 60% 이하를 충족하지 못하였습니다.
     ┌─ 예외조항 확인해보세요 ───────────────┐
     │ (해당 시) 원가구 소득 미고려 조건 참고 │
     └──────────────────────────────────────┘

  필요 서류
  ─────────────────────────────────────────
  [ ] 월세지원 신청서                        [필수]
  [ ] 소득·재산 신고서                       [필수]
  [ ] 신분증                                [선택]


--------------------------------------------------------------------
6. 주의할 점 (팀 전체 참고)
--------------------------------------------------------------------
- status(충족/불충족/확인필요)는 Policy Engine이 계산한 값 으로할지 AI가 해야할지 봐야함. 
- possible_exception, additional_note는 "참고용 안내"이지 확정된
  자격 인정이 아닙니다. 화면 문구도 "~할 수 있습니다 / 확인해보세요"
  톤을 유지하고, "예외 대상입니다"처럼 확정 문구는 쓰지 않는 걸 권장합니다.
- 같은 입력이어도 AI 응답이 매번 100% 동일하지 않을 수 있습니다
  (LLM 특성). 데모 때는 사전에 검증된 예시로 진행하는 걸 권장합니다.
